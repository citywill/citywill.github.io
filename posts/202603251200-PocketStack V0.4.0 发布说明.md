# PocketStack V0.4.0 发布说明

*2026年3月25日发布*

---

本月重点完善了外观定制能力。实现了 Blue / Green / Red / Gray 四套主题色的全局切换，为所有组件适配了深色模式，同时新增了页脚组件支持，提升了系统的视觉多样性和用户体验。

## 新特性

### 主题

- 多主题颜色切换：实现 Blue / Green / Red / Gray 四套主题色，支持全局切换。
- 深色模式：为所有组件添加深色模式支持，自动适配系统偏好。

## 功能增强

- 文档
  - 更新 README 中的大模型评分表格
  - 更新看板文档并添加相关截图
